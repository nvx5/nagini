### ⮻ Project

**A custom, ESP-powered snake vivarium built from 100% second-hand, repurposed IKEA cabinetry.** This personal project combines reclaimed materials, custom 3D-printed ventilation, precision environmental sensing and an integrated LCD control dashboard. Designed to look like a finished piece of furniture rather than a collection of exposed electronics.

The repository is intended both as documentation of the build and as a resource for anyone interested in adapting the hardware or firmware for their own enclosure.

> **Project status:** Build complete. Documentation in progress. Firmware, printable models, component specifications and build measurements will be added as they are prepared for release.

### ♛ Highlights

- 100% second-hand IKEA cabinets repurposed into a vivarium, with custom wooden raised feet and four fully functional drawers.
- Clean-fitting flush sliding glass frontage with an industry-standard enclosure lock.
- Custom 3D-printed, lever-controlled passive intake/exhaust vents alongside an active extraction fan for optimal cross-flow ventilation.
- Vent-integrated air-contact temperature probes plus a combined temperature/humidity sensor.
- Flush ceiling-mounted LED lighting in an aluminium diffuser channel.
- Flush, acrylic-covered LCD dashboard showing target and current temperature/humidity, feeding and shedding records, fan and lighting controls, and environmental graphs.
- An original IKEA cabinet handle repurposed as a hidden control dial.
- Internal cable management with a single outgoing mains plug.
